# Open-source and commercial offerings

This page describes LOOMO's intended product model. Actual rights follow the relevant software licenses, not this marketing description.

## LOOMO ERP: open-source

LOOMO ERP is a branded fork of [ERPNext](https://github.com/frappe/erpnext). ERPNext-derived software remains subject to **GNU GPL v3**, including applicable copyright notices, licensing requirements and corresponding-source obligations upon distribution. The source code has not yet been uploaded here; it must pass a source, security and licensing review first.

## LOOMO AGENT: commercial, in development

LOOMO AGENT is a proposed separately licensed AI-agent offering intended to integrate with LOOMO ERP. It is based in part on the MIT-licensed [Paperclip](https://github.com/paperclipai/paperclip) project. Applicable upstream copyright and MIT license notices must be retained.

LOOMO-owned additions and services may be commercially licensed where applicable third-party licenses and the actual integration architecture permit. LOOMO AGENT is **not included in the planned open-source ERP repository**.

## Future enterprise applications and services

LOOMO plans to build additional commercially licensed offerings that extend ERP capabilities without modifying ERPNext core code where practical. **Separate repositories, standalone deployment or API use do not alone prove legal independence from GPL-covered code.** Each component and integration needs technical and legal review before proprietary distribution.

## Managed SaaS roadmap

LOOMO plans a managed subscription offering combining LOOMO ERP and eligible LOOMO AGENT capabilities. This does not change the GPL rights of the ERPNext-derived code.
